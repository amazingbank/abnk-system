# Bolt.new 提示词 — Amazing Bank 官网 Landing Page

> **用途**：在 bolt.new 中生成 ABNK 官网 Landing Page 高保真原型。
> **范围**：本阶段仅做 landing page 单页——不做登录入口、工作台与任何功能页面，不出现任何银行业务细节。
> **风格**：整体参考 palantir.com 的 UI/UX，配色改为银行特质的暖色调。
> **依据**：`abnk-design/01-product/`（定位）+ ASDM 产品官网口径（`asdm-ai-2026`，asdm.ai）。
>
> **使用方法**：将「主提示词」整段发给 bolt.new；生成后按需追加「迭代提示词」。
> 注：旧版（含登录入口/四工作台/菜单体系/交互范式）已从本文档移除，如需可从 git 历史找回。

## 一、主提示词（整段复制发送）

```text
你是资深产品设计师兼前端工程师。请为 "Amazing Bank"（简称 ABNK）构建官方网站 Landing Page 的高保真原型——单页滚动式品牌站。本阶段只做这一个页面，不做登录、不做工作台、不做任何功能页面。

ABNK 的双重身份（叙事基调，页面需体现）：
1. **对外是一家银行**——服务全球用户的国际化数字银行，首批业务落地中国市场，市场拓展路径：中国本土 → 东南亚 →「一带一路」沿线 → 发达国家市场。
2. **对内是一个范本**——生长在 ASDM（AI 优先的系统开发方法和平台，asdm.ai）体系之上的活 demo、真应用：目标是真实可投产的系统，开发流程、代码、设计全部开源，作为企业引入 AI 进行全流程数字化改造的公开范例。

**硬性边界**：全页不出现任何银行业务细节——不写具体产品名称、利率数字、账户/交易/风控/监管报送等术语，只做品牌、理念与体系的叙事。

## 风格基准：整体参考 palantir.com 的 UI/UX，配色改为银行特质的暖色调
- **排版**：编辑部式的克制与严肃——超大标题、eyebrow 小字（大写、加宽字距）、大量留白、严格网格；每个 section = 一个大主张（statement）+ 一段简短克制的说明；少卡片、多排版，信息密度低而权威感高
- **节奏**：深色 Hero 与浅色正文 section 交替，段落分明
- **动效**：极克制——滚动渐显、数字滚动、hover 微妙变化；不用花哨渐变、不用卡通插画、不用营销气泡
- **暖色系 design tokens**（取代 Palantir 的冷灰黑）：
  - 背景双色：暖象牙白 #FAF7F2（浅色 section）/ 深炭咖 #26201A（深色 section）
  - 正文主色：深浓缩咖啡 #3D322A
  - 强调色：铜金 #B08A4F + 琥珀 #D9A55C（用于 eyebrow、细分割线、CTA、高亮数字）
  - 辅助：偏棕的暖灰阶；金属铜色细线做分割
  - 深色 section 内文字用暖白 #F5EFE6，对比度满足 WCAG AA
- **图形语言**：细线网络/节点连线（象征全球金融网络与 ASDM 知识图谱）、克制的暖色微光；整体传达"银行级的稳重 + 工程级的精确"

## 技术要求
- React 19 + TypeScript + Vite + Tailwind CSS 4 + shadcn/ui，图标 lucide-react
- 仅简体中文，文案直接写在组件中，不用 i18n 框架
- 页内结构化数据（里程碑、清单项等）用本地 JSON（src/data/*.json）维护，配 TS 类型；禁止接入任何第三方数据持久化服务（Supabase/Firebase/数据库一律不用），也不用 localStorage
- 单页滚动 + 锚点导航，响应式支持移动端
- 代码组织：src/design-system/（tokens）、src/data/（JSON）、src/components/（section 组件）

## 页面结构（单页滚动，自上而下共七段）
1. **顶部导航**：极简——logo「Amazing Bank」+ 4 个锚点（双重身份 / 全球路径 / ASDM 体系 / 开源）+ 描边款 CTA「预约演示」；滚动后导航背景变实（暖白 + 细底边线）
2. **Hero（深色）**：超大主张（体现"AI 时代的开源数字银行"）+ 一句副标题（双重身份的浓缩）+ 双 CTA「预约演示」「在 GitHub 上审计我们」；背景为暖色细线网络缓动效（canvas 节点连线，铜金高亮，缓慢漂移）；可在角落放 1-2 个克制的大数字（如「5 层 ASDM 产品体系」「100% 开源」）
3. **双重身份区（浅色）**：左右对置两栏编辑式排版——左「一家银行」讲国际化与市场路径，右「一个范本」讲 ASDM 活 demo 与全流程开源；两栏中间用铜色细线分隔
4. **全球拓展路径区（浅色）**：四步里程碑横向步骤条——中国本土（已开通·铜金高亮）→ 东南亚（即将开通）→「一带一路」沿线（规划中）→ 发达国家市场（远期愿景）；每步一句抽象定位说明，不落任何业务细节
5. **ASDM 方法论区（深色）**：eyebrow「POWERED BY ASDM」+ 三大工程横排——知识工程（AI 知道什么）/ 驾驭工程（AI 能做什么）/ 循环工程（AI 越用越好），各配一句抽象化说明；结尾一句 statement："这不是演示，是一套真实系统的全流程开源构建实录"
6. **开源透明区（浅色）**：statement（"开源的银行，透明的工程"）+ 可审计清单横排列表（源代码 / 设计体系 / 架构决策记录 / 开发流程 / 测试与 CI）+ GitHub badge 与开源协议标牌（Apache-2.0 占位）+ CTA「在 GitHub 上审计我们」
7. **页脚（深色）**：极简——一句话定位、GitHub 与 asdm.ai 链接、联系邮箱占位；不放任何具体业务与产品信息

## 交互与细节
- 全站滚动渐显（IntersectionObserver：fade + 16px rise，触发一次即可）
- 导航锚点平滑滚动，当前 section 对应导航项高亮
- hover：细线延伸、文字暖色微亮、按钮描边变铜金，克制不夸张
- 大数字进入视口时滚动增长动画
- 无障碍：WCAG AA 对比度（注意深色 section 中铜金文字的可读性）、语义化标签、全键盘可达

## 验收标准
- 单页滚动结构完整，七段齐全，无死链、无 404、控制台无报错
- Palantir 式编辑排版可辨识（大标题/留白/深浅节奏/克制动效），同时整体呈暖色调银行质感
- 全页无任何银行业务细节（无产品名/利率/账户/交易/监管术语）
- 仅中文、数据为本地 JSON、零第三方服务接入
- 移动端排版不破（≥375px）
```

## 二、迭代提示词（生成后按需追加）

### 迭代 1：Hero 质感打磨
```text
打磨 Hero 的质感与动效：1) canvas 网络动效细化——节点数量与连线密度降低，线宽 1px，铜金高亮仅出现在少数关键连线上，整体缓慢漂移（可被鼠标轻微扰动但不跟随）；2) 叠加极细的暖色噪点纹理（grain，opacity ≤ 3%）提升质感；3) 大标题做一次性的入场动画（fade + 轻微上移，不做循环动效）；4) 移动端关闭 canvas 动效改为静态渐变底。保持 Palantir 式克制，不炫技。
```

### 迭代 2：滚动叙事节奏
```text
统一全站滚动叙事节奏：1) 所有 section 的渐显统一时长与缓动（如 600ms / ease-out），标题、说明、列表依次错开 80ms 阶梯出现；2) 导航增加当前 section 进度指示（锚点高亮 + 顶部 1px 铜色进度条）；3) 深浅 section 交界处做 4-8px 的铜色细线过渡或柔和的暖色渐变衔接，避免生硬切换；4) 增加右下角「回到顶部」细线图标按钮（滚动超过一屏后出现）。
```

### 迭代 3：后续扩展预留
```text
为后续渠道扩展做入口预留（仅占位，不实现页面）：1) 导航 CTA 旁增加禁用态「网银入口 · 即将上线」（灰色、hover 提示 Toast"建设中"）；2) 页脚增加三个禁用链接——个人网银 / 企业网银 / 员工入口，样式统一为"即将上线"占位；3) 不新建任何路由页面，点击行为只弹 Toast。
```

[调试插曲归档]
① 架构调整（必要变更，超出原改动清单）：对客收敛面端点为网关本地 @RestController 聚合，本地请求
   不经 SCG 路由链——GlobalFilter（只包裹 route 执行）无法覆盖本地 controller，受保护路径将裸奔。
   修复 = BearerTokenFilter 由 GlobalFilter 改为 WebFilter（对本地 controller 与 SCG 转发统一生效；
   放行清单/401 载荷/属性键保持 P2.2 口径，auth 单测全量回归 10/10 绿）。同因 BlacklistFilter 直接
   以 WebFilter 实现（order -90，鉴权先行）。

   自动拆箱——Fineract /clients/{id}/accounts 投影对零余额账户（目标账户 12）缺 accountBalance 键。
   修复 = 显式 Double.valueOf 保持装箱类型；单测补投影缺键形态（mock 已含缺键用例的同类防御）。
③ 用户表实例错位：见环境基线段（gateway_users.json 为服务器实例，本地联调用 local 副本对齐
   本地栈种子 clientId）。

   nominalAnnualInterestRate=0.0（DB m_deposit_product_interest_rate_chart 有 3.0% 数据——Fineract
   产品 API 投影不吐 chart，上游行为）；网关 FixedDepositProduct.interestRate 取产品主名义利率，
   chart 细化利率在账户层呈现（GET /fixeddepositaccounts/{id} nominalAnnualInterestRate=3.0 实测）。
   minDepositAmount 取 depositAmount（P0.3 种子起存金额字段——产品投影无 minDepositAmount 键）。
